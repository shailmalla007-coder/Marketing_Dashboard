# Hook Generator

Create scroll-stopping hooks built for Instagram, TikTok, and LinkedIn with authentic storytelling that resonates.

## Features

✨ **Apple-like Design** - Clean, minimalist interface with system fonts
🌓 **Light/Dark Mode** - Toggle between themes with persistent storage
📱 **Responsive** - Works perfectly on all device sizes
⚡ **Fast** - Built with React and Vite for optimal performance
📝 **Smart Hooks** - AI-powered hook templates for maximum engagement
🎯 **Multi-Platform** - Optimized for Instagram, TikTok, and LinkedIn

## Installation

1. Navigate to the hook-generator directory:
```bash
cd hook-generator
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## Usage

1. Enter your content topic
2. Define your target audience
3. Choose your platform
4. Select an emotional trigger
5. Describe what makes your content unique
6. Click "Generate Hooks" to create 5 tailored hooks
7. Copy any hook to use it in your content

## Components

- **ThemeToggle** - Light/Dark mode switcher
- **HookGenerator** - Main form and logic
- **HookCard** - Individual hook display with copy functionality

## Technologies Used

- React 18
- Vite
- CSS Variables for theming
- localStorage for persistence
